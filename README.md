<h1>Austral - Multimedia Portfolio</h1>

<p>
Austral is my original multimedia and creative portfolio, built to showcase my work in graphic design, animation, video editing, and digital media.
</p>

<p>
The website was created from scratch using HTML, CSS, and vanilla JavaScript and represents one of my earliest projects combining my interests in creative design and web development.
</p>

<h2>Purpose</h2>

<p>
Austral was created as a personal portfolio for my multimedia work under the name Austral Lunaris.
</p>

<p>
The project gave me a place to showcase graphic designs, animations, video work, and other creative projects while also allowing me to practice building and designing a complete website without using a frontend framework.
</p>

<p>
This project became an important part of my transition from graphic and multimedia design into software development. Building the portfolio introduced me to creating responsive layouts, handling user interaction with JavaScript, organizing media assets, and developing a website from the ground up.
</p>

<h2>Functionality</h2>

<p>
Austral is a multi-page portfolio containing separate sections for my background, graphic design work, and animation projects.
</p>

<h3>Home</h3>

<p>
The homepage introduces the Austral multimedia brand through a full-screen animated video background and navigation to the rest of the portfolio.
</p>

<h3>About</h3>

<p>
The About page provides information about my background in multimedia, digital design, animation, music, and web development.
</p>

<p>
It also highlights the creative and technical tools I was using while building the portfolio.
</p>

<h3>Design Portfolio</h3>

<p>
The portfolio section displays graphic design work inside a custom image gallery.
</p>

<p>
JavaScript is used to create a lightbox experience that allows visitors to select an image and view it at a larger size.
</p>

<h3>Animations</h3>

<p>
The animations section contains a collection of motion graphics, visualizers, logo animations, and other video projects.
</p>

<p>
A custom JavaScript video lightbox allows selected animations to be displayed separately from the main gallery.
</p>

<h3>Responsive Navigation</h3>

<p>
The website includes a custom responsive navigation menu that can be expanded or collapsed on smaller screens using JavaScript.
</p>

<h2>Backend Experimentation</h2>

<p>
The repository also contains an early backend experiment using Node.js, Express, PostgreSQL, and pg-promise.
</p>

<p>
An Express endpoint was created to query media paths from a PostgreSQL database, giving me early experience connecting a web application to a database and retrieving data through a server.
</p>

<h2>Project Structure</h2>

<p><b>index.html</b> - Main landing page</p>

<p><b>about.html</b> - Background, skills, and software</p>

<p><b>designs.html</b> - Graphic design gallery</p>

<p><b>animations.html</b> - Animation and video gallery</p>

<p><b>database.js</b> - Express and PostgreSQL experimentation</p>

<h3>Optional Backend</h3>

<p>
The repository also contains an experimental Express server.
</p>

<p>Install the required dependencies:</p>

```bash id="w1gn6k"
npm install
```

<p>Start the server:</p>

```bash id="q8pf3s"
npm start
```

<p>
The Express server runs locally on port 3000 and includes a <b>/videos</b> endpoint that queries media data from a PostgreSQL database.
</p>

```text id="81fbzn"
http://localhost:3000/videos
```

<p>
Running this portion of the project requires a compatible local PostgreSQL database configuration.
</p>
